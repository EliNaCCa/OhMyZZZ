# 网络读取

## 国服 Windows 3.3

OhMyZZZ 按一条龙为当前账号配置的游戏目录读取客户端版本。识别到国服时默认选「国服 · 读取导出文件」，已有的国际服选项会自动修正。手动选择的「游戏画面（OCR）」继续生效。

国服读取器 v0.2.1 对应 `CNPRODWin3.3.0`。国际服读取器 v3.3.1 对应 `OSPRODWin3.3.0`。两种导出共用套装和属性规则，副词条次数在导入时换算成同一口径。国服 ZOOD 带有盘的编号，穿戴者和弃置字段在此版本中都是占位值。国际服 ZOD 的穿戴者和弃置标记来自读取器，导出的顺序编号只在当次库存内使用。[国服导出格式](https://github.com/Treageer/zzz-drive-exporter/blob/v0.2.1/src/export_api.rs) · [国际服导出示例](https://github.com/pingwinekZ/zzz_packet_capture_0delay/blob/v3.3.1/rust/testdata/parity/zod_export.json)

在 **OhMyZZZ → 设置 → 运行设置** 点「选择导出目录」，选本账号的读取器输出目录或其中的 `exports` 文件夹。默认位置是插件账号目录下的 `exports`。设置页打开时会自动载入新写入的 `zzz-drives-zood-v1.json`，日常整理也会从同一位置读取。

也可以直接点同一行的「打开读取器」。插件从上游 Release 下载 v0.2.1，核对压缩包和里面每个文件的 SHA-256 后解压到 `plugin_data/drive_disc_manager/_reader/0.2.1/`，再以管理员身份启动，所以 Windows 会先弹出管理员确认。读取器只监听登录通信，不注入游戏、不读内存、不改流量。启动后：

1. 游戏停在登录页。等读取器窗口出现「Capture started」，再登录进入世界。
2. 读取器收到完整的驱动盘数据后自动停止并导出。库存写进上面选定的导出位置，设置页会自动载入。
3. 如果读取器提示按 Enter，说明这次登录的数据不够它单独还原。保持驱动盘不变，完全退出游戏并停在登录页，回到它的窗口按 Enter，再登录一次。
4. 插件最多等 20 分钟。超时会结束读取器；一条龙本身不是管理员时结束不了它，这时请在读取器窗口按 Ctrl+C。

同一时间只能有一个读取器在抓包，否则两边的重组会互相干扰。插件发现已有读取器在运行时不会重复启动，并说明那是哪个账号的。抓包的中间文件保存在本账号的 `cn-captures/`，其中含会话密钥和完整库存，不要外传。

国服读取器在登录时导出一次库存。登录后新刷的盘，要到下一次成功导出时才会出现在文件里。想马上看刚刷的几张盘，可用「仓库预览 → 更多 → 看最近获得的盘」。

「仓库预览 → 更多 → 驱动盘顺序」里的顺序号由 OhMyZZZ 按游戏内的「获得顺序」编排，越新越大。出新盘后继续往上编号，强化沿用原号。最近一批离库的盘会列出原号，有完整排序时同时列出上次的位置。

开启「整理前刷新驱动仓库」后，等待读取器更新时，日常任务会按获得顺序补读新盘，根据仓库多出的张数和上次的读盘记录决定读到哪里，一次最多读当前筛选下的前 36 张。在「仓库预览 → 更多 → 上次读到的新盘」可查看词条和试强化建议。双击一张盘可查看角色攻略和设置同类备用数量。完整库存就绪后继续整理。

仓库按每张盘的编号统计新增、减少和属性变化，包括强化后的等级和词条。国服文件提供驱动盘属性，可用于预览配装。装备者、弃置状态、角色和音擎养成需要其他数据来源。上游作者用国服 3.3.0 的一次历史登录数据导出了 2,335 张盘，其他账号的实时读取仍待验证。[国服读取器 v0.2.1](https://github.com/Treageer/zzz-drive-exporter/blob/v0.2.1/README.md)

要补穿戴者，在「运行设置 → 绑定角色展柜」输入本账号的游戏 UID。刷新导出文件时，OhMyZZZ 用该 UID 查询 Enka 的公开展柜，按驱动盘编号、套装、号位、等级和词条与仓库核对。展柜只覆盖已公开展示的代理人，展示记录有缓存，仓库页会列出读取时间和匹配张数。[Enka 展柜字段说明](https://github.com/EnkaNetwork/API-docs/blob/master/docs/zzz/api.md#equippedlist)

在「配队 → 关卡分队」点「读取角色展柜」，只需游戏 UID 就可以读取公开展示的代理人等级、影画和音擎星级。驱动盘仓库仍由所选的库存读取方式更新。导出文件有穿戴者时直接采用。配装页会标出展柜和上次游戏扫描的记录，六张盘来自同一份记录时才比较面板与输出。

国服仓库导出和游戏扫描都保存为 JSON。一次完整的国服导出就能计算配装和留盘。点「配队 → 一键换装」时，一条龙按方案中的驱动盘编号安排六个号位，用游戏画面确认穿戴者、弃置标记和目标实物。上次扫描已经对上编号的盘，其穿戴记录也按编号查找。

## 国际服 Windows 3.3

在 **OhMyZZZ → 设置 → 运行设置** 选择「国际服 · 网络读取」。

1. 在玩游戏的桌面点「打开读取器」。首次使用会下载经过 SHA-256 校验的 Windows 版，启动时由 Windows 请求管理员权限。
2. 在读取器里打开 **Live export**，保留角色、驱动盘、音擎和穿戴信息，点 **Start capture**，再登录对应的游戏账号。已经在线时需要重新登录一次。
3. 回到 OhMyZZZ 的「仓库」，点「读取仓库」。刷盘时保持读取器打开，新掉落和强化会同步到下一次读取。切换游戏账号时重新打开读取器。

网络库存可以直接用于筛盘和计算配装。自动标记时，插件先留出已保存配装用的盘，再按名额挑备用盘。进游戏后核对每张盘的词条、穿戴和标记状态，再按清单锁定或标记弃置。游戏里已标记弃置的盘沿用原标记。手动换装时会核对所选方案的六个号位。

**每日和每周次数**按一条龙当前账号的刷新日计算。每次任务列表走到 OhMyZZZ 最多运行一轮，成功才计数。比如「每天 1 次、每周 3 次」表示一周最多整理三天。手动读取和手动换装单独运行。

## 它怎么读，有什么风险？

登录时，服务器会把本账号的库存发给游戏客户端。国服读取器 v0.2.1 是面向国服 PC 3.3 的预发布版，使用 Windows 自带的 pktmon 采集登录通信，将驱动盘保存为本地 JSON。OhMyZZZ 读取这份文件。[国服发布说明](https://github.com/Treageer/zzz-drive-exporter/releases/tag/v0.2.1)

国际服读取器使用 WinDivert 的只收、复制模式，OhMyZZZ 通过同一台电脑上的 Live export 接口读取清单。两种读取器在采集时都需要管理员权限。[国际服实现](https://github.com/pingwinekZ/zzz_packet_capture_0delay/blob/cbf8efabbc77d187b6fc16c499b9c39b8e018acd/rust/crates/zzz-capture/src/windivert.rs)

游戏规则和词条倍率是公开资料，仓库明细属于登录账号。官方声明允许对影响公平的第三方工具采取封禁等措施，具体检测规则和单个读取器的封号概率没有公开。OCR 同样使用第三方自动化来翻包。[绝区零公平运营声明](https://www.hoyolab.com/article/30585630)

国际服实时读取使用 **0delay 3.3.1**，对应国际服 Windows 客户端（OSPRODWin）。[读取器 fork](https://github.com/EliNaCCa/OhMyZZZ-Scanner) · [上游发布包](https://github.com/pingwinekZ/zzz_packet_capture_0delay/releases/tag/v3.3.1)
