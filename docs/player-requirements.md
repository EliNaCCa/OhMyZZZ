# Eli 的驱动盘管理要求

更新于 2026-11-28。以下是当前口径，优先于早期开发草案。

## 刷盘后的日常整理

- 一条龙按已有任务顺序运行 OhMyZZZ，勾选任务即可。日常只做筛盘、弃置标记和潜力盘强化。已标记弃置的盘交给拆解任务。
- 成品按套装、号位、主属性和用途筛选，只留我的代理人用得上的 +15。基础备用数可按类配置。每多一位适用的已拥有代理人，增加基础名额的 50%，半张向上取整。同一代理人的多份攻略只算一次。
- 用得上的胚子每次升一档，看实际新增或强化的副属性，再比较。名额未满时补空位。名额已满时，只有某个适用用途仍有机会超过现有成品才继续。剩余机会全中也只能打平时，留原盘，给新盘标弃置。+3、+6、+9、+12 都只是强化过程中的等级。
- 暂时没人用的高潜力胚子停在 +0。全仓合计最多留可用 +15 实物数量的三分之一，向下取整。同一张成品被几个代理人共用只算一张。
- S 盘只有 +3、+6、+9、+12、+15 五次机会。三词条盘第一次只能开不同的第四条。四条已齐时，未来只能强化已有词条。按每个适用角色或自定义用途分别比较有效词条档数。
- 手动保护、穿戴和已启用配装用盘沿用现有保护。资料不足以判断用途的盘等补齐资料再处理。

## 数据、配置和配装

- 国服账号优先接现成国服读取器。缺少适配时继续开发国服路径。以当前游戏版本的国服真实库存作为验收依据。
- 完整网络库存作为依据。OCR 可用于新掉落和现场标记，按获取顺序扫描。国服完整读取和实机强化按实际验收记录报告。
- 首次在游戏内选择「获得顺序」，从最新到最旧实扫全仓，每张盘保存顺序号。用套装名、号位、等级、主副属性和强化档数把盘对应到国服库存里的实物编号。属性完全相同的盘保留各自的顺序，能区分实物时再绑定编号。以真实账号的网络导出和游戏内总数相符作为全仓网络读取的验收条件。
- 以后按本账号前后两份国服库存的驱动盘编号算增量。游戏按「获得顺序」从最新往回找，找齐本轮目标就停。新增盘、强化过的旧盘和需要改变留弃决定的盘进入本轮清单。后续内置拆解使用游戏里的弃置标记，旧盘去向由下次国服库存核对。
- OhMyZZZ 按游戏里实际看到的获得顺序给盘编本地顺序号，越新越大。留盘、强化沿用原号，离库后也保留这次变化里的原号。只记先后。
- 本地规则优先，上游更新与本地修改冲突时，在一条龙的配置页显示具体规则。优先使用游戏内称呼。启动更新提示可关闭，合并几个改动再发小版本，附更新日志。
- 配装按需运行，考虑已拥有代理人、队友增益、敌人和当期环境，多队同时出场时分开分配。主 C 的满爆目标为实战 100%，超过的暴击率不计收益，满爆方案之间选总伤更高的。
- 本地直接安装，验证只跑相关冒烟。在玩家用主桌面时只用后台命令。

## 已处理的口径冲突

| 旧口径 | 当前口径 |
|---|---|
| 胚子一律先升 +3，失败也可留作备用 | 无人适用的高潜力盘留 +0。有人适用的按档强化，无望超过现有盘就弃置 |
| 所有 +15、推荐盘或天然四词条双暴永久保留 | 按适用代理人、同类名额和全仓胚子上限筛选 |
| 每次刷盘后重新给所有队伍配装 | 日常只维护盘库，需要时再配装 |
| 满爆有 2.4% 或伤害容差 | 按实战 100% 满爆处理 |

当前实现将无人适用的 +0 高潜力盘定义为同一用途至少有两条有效副属性，优先留命中更多有效词条的盘。同分优先留四词条和已有的备用锁。手动保护的盘独立保留。

小样本已验证一至三人共用的名额、全仓 +0 上限及 +3 实际开词条后的继续或弃置。当前账号仍缺经过核对的完整库存和一次消耗材料后的强化记录。
