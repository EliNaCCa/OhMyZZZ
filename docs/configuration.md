# OhMyZZZ 配置示例

在 **OhMyZZZ → 运行设置** 可以编辑当前账号的 JSON。下面是单个配置片段，将对应字段合并到现有配置即可。套装和属性使用扫描导出的 ZOD 名称。

## 给同类盘留不同的备用

~~~json
{
  "reserve": 2,
  "reserve_rules": [
    {"set":"WoodpeckerElectro", "slot":"4", "main":"crit_dmg_", "purpose":"通用", "count":0},
    {"set":"WoodpeckerElectro", "slot":"4", "main":"crit_dmg_", "purpose":"偏暴击", "stats":["crit_"], "count":3}
  ]
}
~~~

普通类别额外留 2 张。啄木鸟电音的 4 号暴伤主属性盘按「偏暴击」用途额外留 3 张。第一条覆盖该类别的通用名额。填写 null 表示不限，单张「始终保留」和配队占用均不消耗额外名额。

默认完整保留订阅推荐盘。在仓库预览选中一张盘，点「同类备用数量」，可按用途设定名额，并为该类别选择「推荐盘也按同类名额筛选」。对应 JSON 字段为 `trimRecommended`，可设于单条备用规则或全局。已穿戴、已锁、个人保护和启用配队占用优先保留，身份或用途待核的盘留待复核。

## 保存配队

在配装器调整角色、音擎、套装和增益并保存目标。在「我的配队」点「从配装器保存为配队」，填入配装器显示的本机地址并另存为新名称。配装器重启时可能分配新端口，可在运行设置调整 optimizer_url。

~~~json
{
  "name":"艾莲 · 常用队",
  "agentKey":"Ellen",
  "simultaneous":"两队同时出场",
  "tolerancePct":0.5,
  "enabled":true
}
~~~

以上字段位于 profiles 数组的单个方案中。保留导入时保存的 request 字段，其中包含该角色的配装器参数。同组方案按列表顺序决定优先级。预览同时出场的队伍时，会在候选中寻找全员都能使用的六盘组合。满暴容差也可在「我的配队」直接修改。

## 订阅、早场与开发

- 规则页可以按字段设置 inherit（继承）、add（额外接受）或 only（只接受）。角色攻略中的图片套装和条件词条支持在 roster 的 sets 和 mainMap 中设置个人映射。
- 使用 EliSR 包装器时，安装早场钩子后可在「运行设置」开启「早场刷后运行」。每次运行结果保存在账号目录的 early-result.json。[早场钩子](../integration/early-hook.ps1)
- 开发冒烟运行 `python scripts/smoke.py`。构包使用 `python scripts/package_manager.py`，在 dist 目录生成可导入的 ZIP 和 SHA-256。

## 换装与恢复

在「我的配队」选一行，点「设为出场 / 取消」。启用后会同时打开本轮扫描。再次点击可取消出场。驱动盘管理运行时会给所选方案和同一「同时出场组」里的角色穿戴目标盘。仅需试换装时，可单独运行插件，保持「锁定保留盘并标记弃置」关闭。

插件通过扫描器词典核实代理人姓名，读取盘详情和当前穿戴按钮。换装中断后，下次运行会按本轮库存重新计算、再读穿戴状态，已在位的盘直接跳过。账号目录中的 `equip-result.json` 保存目标角色、实物指纹、尝试的动作和最终复读的号位。

当前界面适配使用中文键鼠布局和默认代理人快捷键 C。六盘轮盘和选盘列表的位置参考公开扫描器，中文盘详情、穿戴按钮及跨角色借盘弹窗需要在游戏中继续验证。[布局参考](https://github.com/samsaq/ZZZ-Scanner/blob/ed260460ea84a749ae835ad7e835b72fea9217f3/Python_Scanner/getImages.py#L53-L151)

## 启动提示与回退

启动一条龙图形界面后，OhMyZZZ 在后台检查本仓库发布的插件版本，包含预发布版。有新版时会显示当前版本和可用版本。一条龙空闲时选择 **立即更新**，插件会下载指定版本、校验 SHA-256、备份旧版，然后通过一条龙重新加载任务和设置入口。也可选择 **退出后更新**，在关闭一条龙后安装已确认的版本。选择 **稍后** 会在下次启动时再检查。选择 **关闭启动提示** 会保存你的偏好。

在 **OhMyZZZ → 版本维护** 可重新开启提示，或随时点 **立即检查更新**。自动提示也遵守一条龙的全局插件更新提示开关。已确认的安装在其他一条龙任务占用时会顺延到下一次正常退出。

更新后会用独立进程载入插件入口并读取账号配置。验证失败会恢复旧版。你也可以在版本维护页选择 **退出后回退上一版**，或在退出前取消待办。账号配队、规则和操作记录保存在各自的账号目录。备份和维护记录保存在 `plugin_data/drive_disc_manager/_maintenance/`。
