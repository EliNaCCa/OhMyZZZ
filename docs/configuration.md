# OhMyZZZ 配置示例

读取方式和次数在 **设置 → 运行设置**。[配置网络读取器](network-reader.md)。

在一条龙打开 **OhMyZZZ → 规则 → 规则订阅**，可按中文角色名、套装名、号位或来源查找。输入「摇摆爵士 5号」会定位到该套的五号主属性。点「编辑规则」，选「额外接受」或「只接受」，勾选需要的中文主属性并保存。「额外接受」会随上游继续更新其他推荐。打开配置页时，有分歧的字段会出现在「只看冲突」列表。

要为角色额外留某个套装，可以搜索「艾莲 两件套」，点「编辑规则 → 额外接受」，在套装列表中按中文名搜索并勾选。四件套和两件套分别保存。

搜索「艾莲 副词条」可以查看上游原文，再用中文勾选。上游把「CR%」改写成「CRIT Rate」时沿用同一选择。如果它新增了「只接受」之外的词条，或移除了你勾选的词条，配置页会提示分歧。遇到无法识别的副词条时，符合该角色套装和主属性的盘会显示原文，供你复核。

「运行时自动更新订阅」按账号保存。勾选后，运行 OhMyZZZ 时会在距上次成功同步超过 24 小时后更新。取消勾选可手动点「更新来源」。旁边显示最近成功时间和规则版本，拉取失败时仍可使用这份规则。

在 **设置 → 运行设置 → 高级配置** 可编辑当前账号的 JSON。同一次打开配置页期间，切换账号或更新订阅都会保留各自的草稿。点「保存配置」时只写入草稿改过的项；同一项在别处有不同的更新时，界面会指出冲突项。「放弃草稿」会显示磁盘上的最新配置。下面的配置片段使用扫描导出的 ZOD 名称。

## 给同类盘留不同的备用

还没扫背包时，可以直接打开 **备用规则**。选择套装、号位和主属性，范围可选「所有」。比如选择「摇摆爵士、5 号位、所有主属性」，把偏暴击设为 2 张，再切到偏暴伤设为 4 张，一次保存两个用途。每种主属性分别计算名额。同一张实物同时入选两个用途时，最终只计一张。双击已有规则可调整名额，选「继承」可撤销该用途在这个范围的覆盖。

先在当前一条龙账号的游戏里进入大世界，回到「仓库预览」点「读一张盘」。OhMyZZZ 会打开驱动仓库，显示当前盘两次一致的词条数值、锁定和弃置状态。单盘读数单独保存在本账号的 `single-disc.json`，批量预览继续使用完整库存。

首次建库时，打开当前账号的游戏，在「仓库预览」点「扫描仓库」。一条龙会逐格读取驱动盘，将核对过总数的库存保存到当前账号，再用已保存的规则和配队生成建议。该按钮只执行扫描和预览。日常标记和出场换装仍由任务入口执行。

从 OhMyZZZ 发起仓库扫描时，每张盘会记录主属性数值和同一行的副属性数值。配装器用这些读数计算未满级盘。标记和换装前会复读数值。旧扫描仍可预览，游戏执行使用本轮扫描的读数。

已有启用配队时，缺少套装译名或主属性数值的 S 盘会列出待复核原因。在仓库点「重新计算」或在配队点「计算配装」，可以在搜索配装期间继续查看规则。切换账号时，预览会保存到发起计算的账号。

在「规则 → 角色留盘」勾选「为已拥有的角色留盘」，插件会记住当前账号通过 OCR 或网络读到的角色，包括从驱动盘上认出的装备者。下次只扫驱动盘时，这些角色的留盘规则仍会生效。选中角色后可点「移出所选角色」调整。

在 **仓库预览 → 查看盘详情** 可以点「始终保留这张」，也可以按套装、号位、主词条和用途设置「同类备用数量」。单盘实测后即可设置名额。「配队与备用」会列出当前名额，导入完整库存后会显示实际入选的张数。

仓库预览支持同时按用途和关键词筛选。例如选「额外备用」，输入「摇摆爵士 5号」，可以查看这一套五号位额外保留的盘。选「已标记弃置」可以查看上次扫描时已挂弃置标记的盘。

打开「同类备用数量」，选择通用、偏暴击或偏暴伤。选「为此类盘单独设置」可以填 0 张、指定张数或不限。选「继承」可以恢复框内显示的上级名额。例如清掉五号位攻击主属性的偏暴击覆盖后，该用途会重新跟随已有的套装规则。推荐盘筛选策略作用于该类盘的所有用途。

有当前库存预览时，改完名额可以先点「预览这次调整」。结果显示所选范围内调整前后各保留多少张、其中有多少张备用，以及会新增多少张弃置候选。偏暴击和偏暴伤同时选中同一张盘时，备用总数只计一次。

你在游戏里撤销盘上的弃置标记后，下一次完整扫描会把原因记为「手动撤销弃置后保留」。如果以后想让这张盘重新参与筛选，在仓库预览选中它，点「取消这张盘的撤销弃置保护」。它会按当前配队、备用规则和其他保护条件重新计算。

保存备用名额时，插件会复用这份库存已经算好的配队，并按新名额重排备用盘。库存、启用方案、套装译名、配装器地址或插件版本变化时会重新分盘。在「仓库预览」点「重新计算」也可主动重算配队。

点「添加用途」可以给异常队单独留盘。填写用途名，勾选异常精通、攻击力百分比等需要的副词条，再填备用数量。每张备选盘按所勾副词条的总档数排序。在「通用 → 编辑副词条」勾选「优先匹配角色的有效副词条」，可以保留当前名额，让排序重新跟随角色。选「继承」会恢复上级规则的名额和排序。

扫描器导出时会合并同词条盘。OhMyZZZ 用黄色选中框核对同一页不同列的实物，保留每张盘自己的读数和标记状态。同一列里的相同盘，只有在滚动条位置和旁边两列的盘面都匹配、选中框相隔至少一行时才分别计数。跨页重叠取单页已证实的最大张数。核对后仍有差额，配置页提示游戏内数量和导出数量，并沿用上次完整库存。同属性盘可在预览里查看，整组等待人工复核。

扫描器也可能合并词条档数相同的不同品级盘。OhMyZZZ 会核对各自的强化上限、主属性数值和选中位置，把能区分的实物恢复为单独条目。

仓库预览会读取游戏中的锁定状态。手动锁和旧版本留下的锁在同类名额之外保留。锁定提示模糊的盘进入待复核。

双击仓库中的盘，或选中后点「查看盘详情」。在「规则来源」选一个字段，可看到参与这次判定的页签、上游值、个人覆盖和生效值。存在冲突时还会显示上游变动前的值。「配队与备用」列出占用这张盘的方案和备用名额，可直接跳到对应配队。「判定明细」解释保留、待复核或弃置的原因。旧版预览重新计算一次即可补全来源；只有单盘实测记录时，详情显示那次读数和当前规则。

调整名额或等待后台计算时，可以留在当前详情页查看新结果。只要这张盘的属性在刷新前后都能唯一对应，即使新建议把它移出了列表筛选范围，页面也会保留当前盘和打开的标签。若盘已消失或有同属性重复盘，页面会返回仓库供你重新选择。

自动标记会核对滚动条位置和列表画面，经过整页重复盘或待复核盘时会继续找本轮目标。若列表停止移动而还有目标盘未核实，运行记录会显示停在哪一步以及剩余张数。

例如同类备用设为 1 张，插件上次锁好的备用盘会继续占这一张。想让刷到的好盘顶替它，就在「设置 → 运行设置」打开「优先留更好的备用盘」。开启标记后，插件会先锁好新备用，再解开旧备用锁。关闭自动替换时，调低名额会保留已经锁好的备用盘，仓库会显示多留了几张。手动锁盘和配队用盘各自保留，备用名额留给其他盘。

你在游戏中手动解开备用锁后，下次扫描会把该盘列为「手动解锁后保留」。要让它重新参与自动管理，可在仓库预览选中它，点「取消这张盘的手动解锁保护」。

「保留满级盘（+15）」和「保留四词条双暴胚子」默认开启。四词条双暴胚子指掉落时就有四条副属性，同时带暴击率和暴击伤害。受保护的盘独立保留，同类备用名额留给其他盘。

以 S 级盘为例，副词条总档数减去已获得的强化次数，就是初始词条数。一张 +3 盘显示四个各一档的副词条，说明它起初有三条，第一次强化开出了第四条。预览显示初始词条数和剩余强化机会。偏暴击、偏暴伤名额分别从已有对应词条的盘中选取，库存不足时显示实际覆盖数。

四张样盘使用 Kayco 的 Balanced 设置、空角色名单，以及 OhMyZZZ 的同类备用 0 张做了对照。已知套装四号位防御主词条中，原生四词条双暴盘两边都保留，+3 才补齐四条的双暴盘和普通三词条盘在这组条件下都进入弃置候选。带未知副词条的盘在 Kayco 显示保留，在 OhMyZZZ 显示待复核。这个对照使用公开计算脚本和演示数据。[Kayco 判定规则](https://kayco.app/zzz/disc-triage) · [计算脚本](https://kayco.app/src/zzz-triage.js)

~~~json
{
  "reserve": 2,
  "reserve_rules": [
    {"set":"WoodpeckerElectro", "slot":"4", "main":"crit_dmg_", "purpose":"通用", "count":0},
    {"set":"WoodpeckerElectro", "slot":"4", "main":"crit_dmg_", "purpose":"偏暴击", "stats":["crit_"], "count":3}
  ]
}
~~~

普通类别额外留 2 张。啄木鸟电音的 4 号暴伤主属性盘按「偏暴击」用途额外留 3 张。第一条覆盖该类别的通用名额。填写 null 表示不限，单张「始终保留」和配队占用均不消耗额外名额。

默认完整保留订阅推荐盘。在仓库预览选中一张盘，点「同类备用数量」，可按用途设定名额，并为该类别选择「推荐盘也按同类名额筛选」。对应 JSON 字段为 `trimRecommended`，可设于单条备用规则或全局。已穿戴、已锁、个人保护和启用配队占用优先保留，身份或用途待核的盘留待复核。

## 保存配队

强攻和命破按实战属性复算输出。暴击期望使用封顶后的暴击率，命破使用贯穿力和贯穿伤害加成。计算会核对配装器返回的显示值。若模型对不上，当前配队进入待复核。输出非常接近时，插件按复算值比较，再应用该配队的满暴偏好。选择一个方案可查看所选输出、候选最高输出和各窗口的属性。

比如某套装备在爆发窗口达到 109.6% 暴击，详情会显示有效暴击 100%、溢出 9.6 个百分点。按 100% 计算后，若攻击、暴伤等属性让这套盘的总输出仍然最高，插件会选它。常态窗口按自己的加成单独计算。

支援、击破、异常等职业沿用导入的配装器目标。在 **配队 → 面板对比** 查看当前六盘、所选六盘、换装差值和目标口径。普通模式按配装器的下限或区间筛选。严格指标模式按优先级排序，例如目标冲击力 140、所选 118 时，表中显示偏差 −22。异常精通显示角色面板值，战斗内加成另由配装器计入。当前六盘无法核实时，当前值和换装差值显示「—」。模型无法核实时，选择依据显示可取得的面板读数，配队进入待复核。

「配队」显示初选送入配装器的盘数、评估套次和去重后的候选数。同一组六张盘出现在多个窗口或目标中时，评估套次会分别计数。达到单次返回上限时，页面会标出搜索范围。

在 **配队 → 配装器** 选代理人、音擎、四件套和两件套，在配装器内保存角色目标，再点页面右上角「导入方案」并给配队取名。之后在「我的配队」计算配装。页面使用一条龙的 Qt WebEngine，托管的配装器在离开页面时关闭，角色目标按账号保存。

改动已有目标后，在「配队」选中方案，点「更新所选配队」。确认页列出变动的字段，可展开详情对照数值。更新只作用于所选方案，原有分组、出场选择、窗口和满暴容差继续生效。共用同一个配装器目标的另一套队伍可以保留旧快照。

旧方案缺少换装角色，或绑定指向其他代理人时，更新页会列出原绑定和从当前角色字典识别的新绑定。核对后点「更新配队」即可修复。实际换装前会核对同时出场的每个角色，遇到无法唯一识别的名字会提示对应方案。

计算预览时，插件按目标角色匹配扫描到的穿戴者。旧方案缺少绑定时也可比较该角色当前已穿的盘。若已保存的绑定与当前字典冲突，这组方案和依赖它的弃置建议会进入待复核。

默认从上游 Release 下载已验证的 Windows 配装器 v2.3.31.1，每次启动前核对 SHA-256。已有独立配装器的玩家可以在「连接设置」指定其本机 HTTP 地址。清空地址即可使用托管模式。[上游发布页](https://github.com/xliuforge/ZZZ_Multi_Agent_Drive_Optimizer/releases/tag/v2.3.31.1)

~~~json
{
  "name":"艾莲 · 常用队",
  "agentKey":"Ellen",
  "simultaneous":"两队同时出场",
  "tolerancePct":0.5,
  "enabled":true
}
~~~

以上字段位于 profiles 数组的单个方案中。保留导入时保存的 request 字段，其中包含该角色的配装器参数。在「配队」选中方案，点「分组与优先级」。同场角色使用相同组名，1 最先分盘。轮到下一个角色时，插件扣除前序角色占用的盘，用剩余库存重新请求候选。若后面的角色凑不齐六盘，会回头尝试前面角色的其他组合。选中方案可以看初选数量、可用候选数和让盘原因。同一主 C 的不同配装可留空组名或放入不同组，库存清理会保护所有启用方案用盘的并集。

## 订阅与日常运行

在 **配队 → 管理方案 → 输出窗口** 为强攻或命破设置常态、爆发等不同时段。勾选「按窗口输出占比计算配装」，填写各窗口的占比，并选择在哪个窗口判断满暴。比如常态填 20，爆发填 80，插件就用同一套六张盘分别计算两个窗口，按 20% 和 80% 合计。默认满暴最多可以少 0.5% 输出，超过就选输出最高的一套。大库存按配装器返回的候选范围搜索。

每项增益可填写来源、词条、数值和计算方式。队友的额外增益选「本窗口额外生效」。角色或音擎已经计入导入配置的增益选「配装器已计入」。若其中一项实战加成只在爆发期间生效，在常态窗口填同一来源的数值并选「已计入，本窗口不生效」。占比和主要窗口按配队保存，关闭窗口评分会保留配置。

本地接口冒烟使用七张演示盘。常态占比 20% 时四号位选择暴伤，常态占比 95% 时选择暴击。对已支持的直伤模型，插件用未舍入的复算值加权，并与配装器返回的四位小数核对。同优先级内精确同分时沿用现有盘。[配装器 v2.3.31.1](https://github.com/xliuforge/ZZZ_Multi_Agent_Drive_Optimizer/releases/tag/v2.3.31.1)

八张盘的覆盖冒烟给三、四号位各两种暴击或暴伤选择。四种六盘组合全部进入候选。常态与爆发按 1∶2 加权后，四组未舍入输出及主要窗口的有效暴击率均与独立枚举一致。可以用 `python scripts/candidate_coverage_smoke.py` 在临时账号复核这组样盘。

- 「保留本地」确认当前分歧，「采用上游」恢复继承。「合并」把你原来指定的值改成额外接受，上游的其他推荐继续随订阅变化。下次远端更新涉及新的分歧时，配置页会再次提示。
- 在一条龙日常任务列表勾选 OhMyZZZ，并把它排在刷盘之后。新账号自动扫描仓库并计算预览，已有账号会沿用保存的选择。
- 想锁定保留盘和标记弃置时，在「设置 → 运行设置」打开对应开关。把内置「驱动盘拆解」排在 OhMyZZZ 后面，开启「全选已弃置」即可在同一轮处理游戏里原有和新标记的盘。
- 开发冒烟运行 `python scripts/smoke.py`。构包使用 `python scripts/package_manager.py`，在 dist 目录生成可导入的 ZIP 和 SHA-256。

## 换装与恢复

在 **设置 → 库存记录** 查看上次离库和新刷到的盘。遇到清单外少盘、重复盘或新盘词条没读清，页面会列出需要核对的盘。核实后点「我已在游戏中核对」。

扫描器导出中文套装名时，OhMyZZZ 会按对应的订阅字段筛盘，继续用库存中的原始指纹识别你的单盘保护。随包补充的六套名称取自同一套装 ID 的简中和英文条目。[套装 ID](https://github.com/EnkaNetwork/API-docs/blob/26b4ddcd045a1264d0a8ef3ef5a3a3e33cbe16ce/store/zzz/equipments.json) · [名称对照](https://github.com/EnkaNetwork/API-docs/blob/26b4ddcd045a1264d0a8ef3ef5a3a3e33cbe16ce/store/zzz/locs.json)

单盘冒烟使用上游归档的「谶羽之誓」五号盘两帧画面，以及一条龙 PP-OCRv6 和仓库扫描器。两帧分别读到「弃置」和「解除弃置」，对应同一实物指纹。插件用 FeatheredFate 查询该盘的订阅规则。[回放样本](e2e/recap_20261101/mark_before.jpg)

临时换队时，在「配队」选中已算好的方案，点「一键换装」查看同组角色的用盘和装备者。点「重扫并换装」后，插件读取游戏库存，逐件穿戴并核对。重扫结果有变化时，点「查看换装变化」可对照各号位的词条和装备者，再决定是否采用最新配装。

想在每次驱动盘管理运行时穿戴某队，可点「设为出场 / 取消」。启用后自动打开本轮扫描，再次点击可取消。

插件通过扫描器词典核实代理人姓名，读取盘详情和当前穿戴按钮。换装中断后，下次运行会按本轮库存重新计算、再读穿戴状态，已在位的盘直接跳过。账号目录中的 `equip-result.json` 保存目标角色、实物指纹、尝试的动作和最终复读的号位。

跨角色借盘前，插件会打开原角色的对应号位，核对这张盘。如果换下的旧盘也是队友要用的，插件会跟踪它回了背包，还是换到了借出方身上，再给下一位角色穿戴。

当前界面适配使用中文键鼠布局和默认代理人快捷键 C。六盘轮盘和选盘列表的位置参考公开扫描器，中文盘详情、穿戴按钮及跨角色借盘弹窗需要在游戏中继续验证。[布局参考](https://github.com/samsaq/ZZZ-Scanner/blob/ed260460ea84a749ae835ad7e835b72fea9217f3/Python_Scanner/getImages.py#L53-L151)

## 启动提示与回退

启动一条龙图形界面后，OhMyZZZ 在后台检查本仓库发布的插件版本，包含预发布版。有新版时会显示当前版本和可用版本。一条龙空闲时选择 **立即更新**，插件会下载指定版本、校验 SHA-256、备份旧版，然后通过一条龙重新加载任务和设置入口。也可选择 **退出后更新**，在关闭一条龙后安装已确认的版本。选择 **稍后** 会在下次启动时再检查。选择 **关闭启动提示** 会保存你的偏好。

在 **OhMyZZZ → 版本维护** 可重新开启提示，或随时点 **立即检查更新**。自动提示也遵守一条龙的全局插件更新提示开关。已确认的安装在其他一条龙任务占用时会顺延到下一次正常退出。

更新后会用独立进程载入插件入口并读取账号配置。验证失败会恢复旧版。你也可以在「版本更新」选择 **回到上一版**，或在退出前取消排队。账号配队、规则和操作记录保存在各自的账号目录。备份和维护记录保存在 `plugin_data/drive_disc_manager/_maintenance/`。
