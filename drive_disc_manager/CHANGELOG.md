# OhMyZZZ 更新日志

## 待发布

- 「配队 → 关卡分队」从本账号角色池重新组队。选各路弱点、抗性和环境增益，式舆比较三队，危局可从三路里选两路。页面标明按条件初选的阵容。
- 调整备用数量时，点「预览这次调整」就能看到偏暴击、偏暴伤各留几张，以及有几张盘两边都能用。高级配置只填这两种用途的名称和张数时，也会按对应的副词条挑盘。
- 读仓库中断后，再次读取会逐盘核对画面。词条画面相同的盘可以复用上次的识别结果，锁定、弃置和穿戴状态按本次画面读取。
- 角色攻略表里的四件套图标也参与留盘。两张表推荐的套装都能保留，在「盘详情 → 规则来源」可看推荐来自哪张表、适合什么队伍。
- 同场配装时，如果候选都抢同一张盘，插件会试着把盘留给需要它的队友，再按角色优先级补算。可在「配队 → 计算详情」查看让了哪个号位。
- 在「盘详情 → 规则来源」点「表格原文」，可查看计算时用到的页签、单元格和原文。1–3 号盘单独显示套装收录依据。
- 在「配队 → 管理方案 → 队伍成员」保存两名队友和影画。输出窗口里的增益可以跟随队友和影画生效，结果见「计算详情」。
- 标记弃置时断线，下次扫描会核对已经标好的盘。刚点弃置就断线的盘会出现在「库存记录」里，方便逐张核对。
- 直伤配队默认允许差一条暴击率。实战暴击达到 97.6% 后比整场预期输出，超过 100% 的暴击率不计收益。「配队 → 管理方案 → 满暴偏好」可按队调整暴击率下限。旧配队采用新默认值。
- 「队伍成员」会列出本账号已读取和手动登记的代理人，选人时带入已知影画。已有方案沿用已保存的影画。
- 给同场角色换装时，如果换下来的盘还要给队友用，插件会核对它现在穿在谁身上，再继续换。

## 0.3.1

- 在「配队 → 配装器」选代理人、音擎和套装。保存角色目标后，直接点右上角「导入方案」，整套操作都在一条龙里完成。
- 「运行设置」和仓库里的留盘理由统一使用「满级盘（+15）」「四词条双暴胚子」等叫法。
- 同类备用设为 1 张时，之前由插件锁好的备用会占这个名额。开启「优先留更好的备用盘」后，评分相同沿用旧盘。
- 选择「保留本地」后，再打开同一条规则并原样保存，会记住之前的选择。

## 0.3.0

- 在「设置 → 运行设置」可选游戏画面（默认）或网络读取。网络读取可用来预览仓库和配装，标记和换装前仍会核对游戏画面。国服网络读取待实机验证。
- 日常整理可设每天、每周最多几次，成功才计数。手动读仓库另算。
- 刷完只扫盘，也会为这个账号之前读到的角色留盘。切换读取方式后，「始终保留这张」仍然有效。
- 一键换装时，套装和角色的中英文名都能对应。如果要换的盘或当前穿戴者变了，到「配队 → 查看换装变化」看哪些号位有变化，再决定是否换装。
- 拆解后刷到的新盘会单独核对。确认旧盘已拆后，同属性的新盘按当前规则重新判断。手动撤销弃置的盘继续保留。

## 0.2.0

- **日常只需勾选一次。** 在一条龙任务列表勾选 OhMyZZZ，放到刷盘之后。新账号默认扫描并预览，想锁盘和标记弃置时到「设置」打开标记开关。已有账号沿用原设置。
- **仓库可以一眼看出哪些盘要留。** 顶部汇总保留、弃置候选和已弃置数量。搜索或筛选后双击一张盘，可查看完整原因、配队用途和同类备用名额。
- **配队、规则和设置都在一条龙内。** 同场分组、满暴偏好和输出窗口收在「配队 → 管理方案」。规则页平时只显示生效结果和来源，有冲突时展开新旧值，供你选择保留本地、采用上游或合并。
- 检查更新时可以先读到新版的中文说明，再决定什么时候安装。在「版本维护」可回看已安装版本的更新日志。

## 0.1.45

- **拆解中断后可以接着清包。** 下一次完整扫描会逐盘核对。若本批盘全部离库、其余盘都对得上，OhMyZZZ 会继续处理。遇到差异时会保留首次核对结果，暂停自动标记。
- **拆解记录按游戏里的筛选条件显示。** 开启「全选已弃置」时，记录会纳入旧标记和本轮新标记。关闭时只按选定品级估算。可以在「运行设置 → 查看拆解记录」核对。

## 0.1.44

- 补回角色攻略表中漏读的三条推荐，包括安东和橘福福的 4 号盘、Roxy 的 6 号盘。
- 上游删掉字段后，你的本地规则仍然生效。规则页和盘详情会显示该推荐原来的页签。

## 0.1.43

- 同场配队分盘时，如果主 C 的输出、近满暴偏好和沿用装备张数都相同，插件会选择能让下一位队友获得更好配装的组合。

## 0.1.42

- 在盘详情修改设置并重新计算后，界面会尽量留在原来选中的盘。仓库标记也会根据列表的实际移动判断是否翻到了下一页。
