# OhMyZZZ 更新日志

## 待发布

- 试到 +3 揭开第四条后，插件会按实际词条重新选备用盘。例如「偏暴击」设为不限张数，四条里都没有暴击率的盘也得靠其他用途才值得留。

- 刷后增量整理时，锁盘和标记弃置都在同一个仓库页面完成。按获得顺序找盘，只在重新进仓时重设排序。

- 等待读取器更新时，新盘会参考上次完整库存里的同类备用盘。只有部分扫描记录时，把鼠标放在新盘建议上，可看到上次扫到的一张同类盘和它的有效词条。

- 试强化会在点「升级」前核对盘名、号位、等级和每条主副属性，能分清同套装同号位的两张盘。

- 国服导出和游戏里的盘数对不上时，日常整理会显示两边各有多少张，只读当前筛选下最近的三张盘。

- 日常整理等待读取器提供库存时，会按获得顺序记录当前筛选下最近的三张盘。打开「仓库预览 → 更多 → 上次读到的新盘」可看主副词条和试强化建议。

- 试强化后会从镀剂窗口回到驱动仓库，读取这张盘的新词条，再决定继续强化、留作备用或标记弃置。全屏找盘时会把鼠标停在仓库列表旁。

- 扫描仓库时，如果没认出选中的是哪张盘，会在当前页补读一次。同一张盘翻页后再出现只算一次，两张词条相同的盘能按位置区分时会分别保留记录。

- 一张盘有几种备用用途时，只有同一种用途既值得试、又有机会追上现有备用，才会花镀剂。有其他用途的盘仍可留着。
- 「看最近获得的盘」和单盘详情会参考当前账号最近的完整仓库预览，并标出预览时间。只读到部分库存时，会注明建议按单盘词条计算。

- 「仓库预览 → 更多 → 看最近获得的盘」会按游戏里的获得顺序，读当前筛选下的前三张，列出主副词条和试强化建议。

- 刷到初始四词条双暴盘时，符合试强化条件的盘可以在同一轮锁好并试一档。玩家自己锁定或解锁过的盘会跳过试强化。
- 「同类备用数量 → 预览这次调整」会单列留着试强化的胚子。已经追不上现有备用的盘，按最终留盘结果统计。
- 试强化按这类盘的备用用途选词条。比如只留暴击率，角色攻略里推荐的异常精通就不会触发强化。单盘详情会写明哪项用途值得试。
- 强化后与仓库中其他盘的属性完全相同时，「上次试强化」会显示停在哪一级。
- 试强化中断后，下次整理会先核对这张盘升到了几级、出了什么词条，再决定留盘或弃置。恢复这一轮只核对结果，镀剂用量为零。
- 试强化会单独算开第四条的机会。例如只留暴击率时，三词条胚子已经有暴击率，升到 +3 只能开出别的属性。手动保护和自己锁定的盘也会留出额外的备用名额。
- 「上次试强化」会写出新开的副属性，或这一档强化前后的数值。
- 国际服用网络读取整理时，会先留出已保存配装用的盘，再挑备用盘。进游戏标记时沿用这份清单，词条或穿戴状态对不上的盘会跳过。
- 在盘详情里能看到是哪套已保存的配装用了这张盘。
- 角色留盘名单会用一条龙的中文名匹配攻略表。普罗米娅和佩洛伊斯现在各自对应一份规则，可直接用于筛盘。
- 在「仓库 → 更多 → 上次单盘读数」里，未锁的背包盘符合试强化条件时，会显示适用角色和建议升到的等级。
- 日常整理按留盘规则和备用数量筛盘。打开「我的配队 → 计算配装」才会搜索搭配，点「一键换装」才会更换驱动盘。
- 仓库可筛选「建议强化」，查看适合的胚子和下一档建议等级。
- 在「运行设置」打开「试强化潜力盘」，可选每次整理最多强化几档，默认 1 档。优先给三词条胚子开第四条，每升一档都用新词条重新比较。
- 备用名额满了，符合规则又有机会追上现有备用的 +0 胚子也会留下试强化。
- 试强化会跟同套装、同号位、同主属性的备用盘比较。哪怕剩下的强化全中有效词条，也追不上各用途的备用盘时，开启「自动标记驱动盘」会把它标记弃置。
- 套装攻略把你想留的主词条从空白改成「不推荐」时，仍按你的设置留盘。「规则订阅」和盘详情会显示具体改了哪个词条。
- 国服调低备用数量时，「预览这次调整」会显示多出几张盘需要进游戏核对。
- 国服日常整理发现配队选中了游戏里已弃置的盘时，会保留弃置标记，从其余库存重新分盘，再按新方案留备用盘。
- 单独给某个套装或号位设置备用数量后，国服整理会按该类别的名额处理推荐盘。
- 「关卡分队」按本期实战成绩比较整组队伍，优先拿满奖励，再看最吃紧的一路。缺少成绩时，按弱点、抗性、环境增益、阵容和已知练度初选。移除了常用搭配的加权。
- 国服可以先在「运行设置」选好读取器目录。导出文件更新后，下次打开 OhMyZZZ 或运行日常整理就会读取新盘和强化变化。
- 国服自动标记首次整理整个仓库。以后有新的仓库导出时，插件会在左下角的筛选里切换到「获得顺序」，从最新的盘开始找。刷到新盘或旧盘需要换代时，找齐本轮用盘就停。接着运行「全选已弃置」时，也会核对未锁盘的弃置状态。
- 自动标记会复用本轮扫描记下的盘位，直接点开目标盘核对词条。仓库顺序变化时，会重新查找剩下的盘。
- 国服开启「优先留更好的备用盘」后，能按编号认回插件上次锁的盘。刷到更好的同类盘时先锁新盘，再解开旧盘。新盘已经穿在角色身上或已标记弃置时，从背包里另留备用。
- 国服和国际服导入的 S 级盘按游戏显示的数值比较。未满级盘的固定攻击力等主属性统一取整。
- 仓库扫描完成后会记住已核对的词条，下次扫到相同详情时可以直接复用。同一列里隔了几页的同款盘，也能按滚动条位置分别计数。
- 首次扫描数量没对上时会保存原始盘位。更新后可在仓库点「重新计算」，用上次的记录生成预览。

- 「关卡分队」可以读取角色展柜，按各路弱点、抗性和环境增益比较分队。关卡适配和阵容构成相同时，优先把 6+5 代理人分给不同队。
- 点「保存到我的配队」可一次保存式舆三队或危局两队。同一名代理人搭配相同队友时沿用已有配装目标和输出窗口。已选目标的角色一起分盘，默认输出角色先选。

- 关闭自动标记时，日常扫描也会记下游戏里原有的弃置盘。同组随后运行「驱动盘拆解」，下次完整扫描就能在「库存记录」查看这些盘的去向。

- 「仓库 → 对比换盘」可以选代理人和号位，查看把穿戴盘换成背包盘后各项词条增减。上次扫描只读到部分仓库也能比较。

- OCR 翻页时会记住盘所在的列。同词条盘出现在不同列时按多张计数，同一列翻页重叠时只计一次。仓库数量还对不上时，已认出的盘可在扫描记录里查看。
- 手动停止扫描时，已读到的盘会保存到扫描记录，已认出的代理人会加入角色列表。下次整理仍使用核对完整的仓库。
- 修正了驱动仓库选中框的识别位置。扫描同词条盘和按方案换装时，插件能认出一条龙实际点中的格子。
- 直伤主 C 优先满暴。算上配队加成后，满暴方案里选预计输出最高的一套；本轮都达不到 100% 时，直接选预计输出最高的一套。移除了满暴容差设置。
- 国服配装预览能认出上次扫描时代理人穿的六张盘。即使那次没扫完整个仓库，只要六个号位的词条都能跟国服库存逐张对上，就能比较换装收益。
- 国服配装和留盘只需一份完整的仓库导出。旧扫描文件读不出来，也能照常计算。拆解前可在「库存记录」看本轮清单；国服导出更新后会按驱动盘编号核对去向。
- 仓库扫描中途结束时，已经认出的装备者也会加入当前账号的角色池。「关卡分队」和「角色留盘」都能选到他们。浅羽悠真和游戏内简称「悠真」会合并成同一名代理人。
- 国服单独换装时，找齐出场方案用盘就开始换装，按每个号位复读结果。日常同时整理全仓时沿用当次扫描。
- 在国服配装预览里可以点「一键换装」。游戏会核对所选方案的六张盘，穿戴者有变化时会列出借盘的角色。同一个主 C 的其他启用方案继续留盘。
- 仓库还没有完整预览时，可以先看上次游戏扫描读到的盘。国服读取器的成品文件放在当前账号的 exports 文件夹后，整理任务会自动导入。
- 国服刷新仓库后按盘的编号核对拆解记录。「库存记录」能分清本批离库、新入库和强化的盘，也会列出清单外少了哪张。

- 国服日常整理沿用网络仓库的驱动盘编号和配队清单，游戏内核对要锁定、弃置和换装的盘。「始终保留这张」可单独保护同词条的某一张，强化后继续生效。

- 国服在「运行设置 → 绑定角色展柜」填 UID，刷新导出文件时会按驱动盘编号和词条认出展示角色的穿戴。配装页标明穿戴记录来自导出文件、角色展柜或上次扫描。

- 国服可以在「设置 → 运行设置」选「国服 · 读取导出文件」。首次在仓库选择本账号的 ZOOD 文件，之后会从同一文件更新库存，按盘的编号核对掉落和强化。配装可按导出的盘预览，游戏内换装仍需核对穿戴状态。
- 国服仓库会对照上次游戏扫描。六张穿戴盘都对上时，配装页会显示方案相比上次穿戴的提升。属性完全相同的两张盘按各自编号计算备用名额。

- 调整备用数量时，点「预览这次调整」就能看到偏暴击、偏暴伤各留几张，以及有几张盘两边都能用。高级配置只填这两种用途的名称和张数时，也会按对应的副词条挑盘。
- 读仓库中断后，再次读取会逐盘核对画面。词条画面相同的盘可以复用上次的识别结果，锁定、弃置和穿戴状态按本次画面读取。
- 角色攻略表里的四件套图标也参与留盘。两张表推荐的套装都能保留，在「盘详情 → 规则来源」可看推荐来自哪张表、适合什么队伍。
- 同场配装时，如果候选都抢同一张盘，插件会试着把盘留给需要它的队友，再按角色优先级补算。可在「配队 → 计算详情」查看让了哪个号位。
- 在「盘详情 → 规则来源」点「表格原文」，可查看计算时用到的页签、单元格和原文。1–3 号盘单独显示套装收录依据。
- 在「配队 → 管理方案 → 队伍成员」保存两名队友和影画。输出窗口里的增益可以跟随队友和影画生效，结果见「计算详情」。
- 标记弃置时断线，下次扫描会核对已经标好的盘。刚点弃置就断线的盘会出现在「库存记录」里，方便逐张核对。
- 「队伍成员」会列出本账号已读取和手动登记的代理人，选人时带入已知影画。已有方案沿用已保存的影画。
- 给同场角色换装时，如果换下来的盘还要给队友用，插件会核对它现在穿在谁身上，再继续换。

## 0.3.1

- 在「配队 → 配装器」选代理人、音擎和套装。保存角色目标后，直接点右上角「导入方案」，整套操作都在一条龙里完成。
- 「运行设置」和仓库里的留盘理由统一使用「满级盘（+15）」「四词条双暴胚子」等叫法。
- 同类备用设为 1 张时，之前由插件锁好的备用会占这个名额。开启「优先留更好的备用盘」后，评分相同沿用旧盘。
- 选择「保留本地」后，再打开同一条规则并原样保存，会记住之前的选择。

## 0.3.0

- 在「设置 → 运行设置」可选游戏画面（默认）或网络读取。网络读取可用来预览仓库和配装，标记和换装前仍会核对游戏画面。国服网络读取待实机验证。
- 日常整理可设每天、每周最多几次，成功才计数。手动读仓库另算。
- 刷完只扫盘，也会为这个账号之前读到的角色留盘。切换读取方式后，「始终保留这张」仍然有效。
- 一键换装时，套装和角色的中英文名都能对应。如果要换的盘或当前穿戴者变了，到「配队 → 查看换装变化」看哪些号位有变化，再决定是否换装。
- 拆解后刷到的新盘会单独核对。确认旧盘已拆后，同属性的新盘按当前规则重新判断。手动撤销弃置的盘继续保留。

## 0.2.0

- **日常只需勾选一次。** 在一条龙任务列表勾选 OhMyZZZ，放到刷盘之后。新账号默认扫描并预览，想锁盘和标记弃置时到「设置」打开标记开关。已有账号沿用原设置。
- **仓库可以一眼看出哪些盘要留。** 顶部汇总保留、弃置候选和已弃置数量。搜索或筛选后双击一张盘，可查看完整原因、配队用途和同类备用名额。
- **配队、规则和设置都在一条龙内。** 同场分组、满暴偏好和输出窗口收在「配队 → 管理方案」。规则页平时只显示生效结果和来源，有冲突时展开新旧值，供你选择保留本地、采用上游或合并。
- 检查更新时可以先读到新版的中文说明，再决定什么时候安装。在「版本维护」可回看已安装版本的更新日志。

## 0.1.45

- **拆解中断后可以接着清包。** 下一次完整扫描会逐盘核对。若本批盘全部离库、其余盘都对得上，OhMyZZZ 会继续处理。遇到差异时会保留首次核对结果，暂停自动标记。
- **拆解记录按游戏里的筛选条件显示。** 开启「全选已弃置」时，记录会纳入旧标记和本轮新标记。关闭时只按选定品级估算。可以在「运行设置 → 查看拆解记录」核对。

## 0.1.42

- 在盘详情修改设置并重新计算后，界面会尽量留在原来选中的盘。仓库标记也会根据列表的实际移动判断是否翻到了下一页。
